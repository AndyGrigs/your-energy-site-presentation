YourEnergy

Платформа для фітнесу та мотивації

Проєкт, створений з пристрастю до спорту, здорового тіла та сучасного дизайну.

Сидячий спосіб життя = ризики для здоров'я

У сучасному світі все більше людей працюють за комп'ютером, ведуть малорухливий спосіб життя та нехтують фізичною активністю. Саме тому платформа YourEnergy актуальна як ніколи!

Наша команда

Команда з 8 студентів, яка разом працювала над розробкою цієї платформи, ділилася задачами, дизайном, API та логікою.
